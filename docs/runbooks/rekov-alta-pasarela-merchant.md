# Rekov: alta de merchant en pasarela

Desk **no** crea la cuenta en Wompi/Bold/MP. Rekov hace el alta comercial/KYC en el proveedor.

## Checklist Rekov

1. Crear o habilitar merchant en la pasarela (sandbox o producción).
2. Entregar al cliente acceso al panel del proveedor para copiar llaves.
3. Indicar al cliente: Desk → **Pasarela** → pegar llaves → **Verificar y activar**.
4. El cliente copia la **URL webhook** que muestra Desk en el panel de Wompi.
5. Prueba: pedido en chat → link de pago → referencia `RK-…`.
